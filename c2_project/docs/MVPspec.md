# MVP 제작을 위한 프로그램 이용 및 작동 시나리오
## 작동 방식 (간략화)
### 0. 이용자가 분석 시작 UI를 클릭한다.
### 1. 웹사이트의 URL 혹은 HTML을 추출하는 확장자를 통해(제작필요) 웹사이트의 정보를 파이썬 서버에 업로드한다.
### 2. 이용자가 키보드로 입력할 수 있는 채팅창이 나오며 해당 웹사이트 내에서 사용가능한, 이용하길 원하는 기능을 입력한다.
### 3. NVIDIA NIM API를 통해 해당 웹사이트를 분석한다.
### 4. opencv를 활용하여 현재 화면에 웹사이트에 어떤 UI가 있는지 분석한다. 
### 5. 3번에서 분석한 내용을 토대로 이용자가 입력한 기능을 실행하기 위해 해야 하는 클릭, 드래그 등의 동작을 판단한다.
### 6. 이용자가 현재 화면에서 할 수 있는 동작을 도형(직선,원 등)의 형태로 표시한다.
### 7. 이용자가 원하는 기능을 수행하거나 우측 상단에 위치한 **종료** 버튼(UI)를 통해 실행을 멈출 때까지 4번-6번의 과정을 반복한다.

# 작동 방식 (상세) 
## 0. 초기설정 
### 0-1. MVP는 크롬 브라우저 기준으로 한다.
### 0-2. 이용자가 띄우고 있는 웹사이트의 데이터를 실시간으로 가져와 파이썬 서버로 보내기 위해 크롬 확장 프로그램이 설치 되었는 지 확인한다. 
### 0-3. 확장자가 설치되지 않았다면 설치한다. 

## 1. 이용 시작전
### 1-1. 이용자가 분석을 원하는 웹사이트를 화면에 띄워 놓는다. 
### 1-2. MVP를 실행한다. 실행 시 **분석 시작** 이라는 문구가 쓰여진 UI를 가진 창을 띄운다. 이용자는 분석 시작 UI를 클릭하여 크롬확장자를 작동시킨다. 
### 1-3. 크롬 확장자가 크롬 브라우저에 적용이 됐는지 확인한다. -> 미적용시 적용한다.

## 2. 웹 사이트 분석
### 2-1. 크롬 확장 프로그램을 통해 현재 탭의 URL과 HTML을 추출한다.
### 2-2. 추출된 데이터를 파이썬 서버에 업로드한다.
### 2-3. 사용자에게 원하는 기능을 채팅으로 입력하게 한다.
### 2-4. NVIDIA NIM API를 통해 현재 페이지 UI를 분석하여 해당 기능을 찾고 수행 경로를 제안한다. 이용자는 NVIDIA NIM API 키를 앱의 설정 화면에 등록한다. 해당하는 기능이 없다고 판단되면 2-3을 반복한다. 
### 2-5. 현재 페이지의 HTML 크기와 UI 요소 수로 요청 규모를 추정하고, 최근 요청량과 함께 고려해 API 요청 간격을 조절한다. 대기 시간·페이지 규모·추정 토큰량·예상 진행률을 이용자에게 표시하고, 실행 중 `분석중` 뒤의 점 개수를 움직여 진행 상태를 알린다. 예상 진행률은 응답 완료 전 92%에서 대기하며, API 한도 초과 응답(429) 시 대기 후 제한 횟수만큼 재시도한다.

## 3. 현재 상태 확인 및 가이드라인 표시
### 3-1. 확장 프로그램이 현재 탭의 보이는 화면 이미지, 뷰포트/문서 크기, 스크롤 위치와 버튼·링크·입력란의 화면 좌표 및 표시 여부를 로컬 Python 서버로 전달한다. Python은 OpenCV로 캡처 이미지를 디코딩하고 윤곽선/화면 영역 후보를 계산한다. 이미지 자체는 NVIDIA NIM으로 전송하지 않는다.
### 3-2. 메인 창에 캡처 해상도와 OpenCV UI 후보 영역 수를 표시한다. 화면 안내 대상 UI가 없거나 화면 밖에 있을 때만 Chrome 페이지 가장자리에 스크롤 방향 화살표와 `-방향으로 스크롤` 문구를 띄우며, 스크롤 위치가 달라지면 화살표 방향도 갱신한다. 메인 창에도 최대화/확대율 조절 또는 관련 영역으로 스크롤하도록 권고한다. 안내 대상 UI가 보이면 크기 조정/스크롤 권고와 화살표를 표시하지 않는다.
### 3-3. 입력칸을 메인 창의 상단 작업 영역에 두고 앱 시작 시 키보드 포커스를 준다. 단계 번호나 단계 진행 문구는 표시하지 않는다.
### 3-4. NIM의 경로 안내에 실제 화면 요소 문구가 포함되면 확장 프로그램이 해당 DOM 요소의 가장자리만 얇은 테두리로 표시한다. 화면 위에 설명 배너, 단계 라벨, 연결선, 어두운 덮개를 얹지 않아 다른 UI를 가리지 않는다. 안내 대상과 입력할 검색어는 Python 앱에 텍스트로 표시하며, 테두리와 스크롤 표시 색상은 `#FF0000`이다. 검색/조회/출력/발급 목표에서는 목표에서 추출한 검색어를 `입력할 검색어`로 분명히 표시한다. 확인할 요소가 보이지 않거나 문구가 일치하지 않으면 자동 클릭하지 않고 직접 찾거나 스크롤한 뒤 다시 캡처하도록 안내한다.
### 3-5. 화면 위 가이드 요소의 투명도는 메인 창 상단 슬라이더로 0%~100% 조절한다. 기본값은 10%이며 0%는 불투명, 100%는 완전 투명이다.
### 3-6. 이용자는 표시된 동작을 직접 수행한 뒤 확장 프로그램에서 현재 화면을 다시 전송한다. 같은 목표를 유지한 채 새 화면을 분석하고 다음 요소를 표시한다. **다시보기**는 현재 페이지에서 저장된 목표 안내를 처음부터 다시 시작한다. **안내 종료**는 표시와 반복 분석을 멈춘다.
### 3-7. 캡처 중 버튼/링크의 존재 여부, 문구, 크기와 위치를 1.2초 간격으로 재측정한다. 유지되는 요소를 우선 선택한다. 화면 갱신 과정에서 DOM이 다시 만들어져도 문구, 접근성 라벨, DOM ID, 유형과 위치를 이용해 대상을 다시 찾고 위치 표시를 갱신한다. 요소가 더는 일치하지 않으면 임의의 다른 UI로 표식을 옮기지 않는다.

## 크롬 확장자 제작 구성
### 1. json, java-script, html 파일로 구성됨.
### 2. MVP 실행 시 현재 열려있는 크롬 브라우저에 적용 되어야 함.
