분석 고마워. 제안해 준 로드맵을 바탕으로 수정 횟수를 줄이고 안정성을 높이기 위해 총 4단계로 압축해서 진행하려고 해.

먼저 **[1단계: 기준 확정, OpenCV 제거, 계측 및 설치 정리]**부터 시작하자. 아래 요구사항대로 작업 계획을 먼저 보여줘.

1. **기준 파일 확정**: `app_270004.py`를 기준으로 삼고, 향후 테스트와 유지보수가 쉽도록 파일 구조 정리 방안을 제안해 줘.
2. **OpenCV 및 스크린샷 제거**: 현재 안내 로직에 쓰이지 않는 OpenCV, numpy 의존성과 스크린샷 촬영/전송/디코딩 코드를 깔끔하게 제거해 줘. (`requirements.txt`와 `check_requirements.py`에서도 제외)
3. **병목 계측 로그 추가**: [확장 수집 시간 / 서버 파싱 시간 / AI 응답 대기 시간 / 전체 소요 시간]을 콘솔과 로그에 ms 단위로 출력하도록 추가해 줘.
4. **설치 스크립트 정리**: `.gitignore`에 대용량 exe 파일을 추가하고, Python 최소 버전 검사를 보완해 줘.

아직 코드를 작성하지 말고, 어떤 파일의 어느 부분을 어떻게 수정할지 **1단계 수정 계획**만 먼저 정리해 줘.

---

1단계 작업 확인했어. 이제 **[2단계: HTML 파서 개선 및 실행 속도 단축]**을 진행하자. 

1. **HTML 파서 및 데모 로직 정리**:
   - `<li>` 내부 버튼, 아이콘(`svg`) 버튼의 텍스트/aria-label, `<img>`·`<br>` 포함 요소가 누락되지 않도록 파서를 개선해 줘.
   - 서버와 확장에 하드코딩된 GitHub `"Contributors"` 데모 로직을 전부 제거해 줘.
2. **목표 분류 단순화**:
   - 시니어의 구어체("증명서 어디서 떼는지", "병원 예약 어떻게 하는지" 등)가 오판되지 않도록 깨지는 정규식 규칙을 정리하고, 애매한 의도는 AI가 문맥으로 직접 판단하도록 프롬프트를 보완해 줘.
3. **속도 단축 (첫 안내 및 단계 전환)**:
   - 불필요한 `page_delay`(4~12초 인위적 대기)를 제거하거나 최소화하고, HTML 파싱을 서버 락(Lock) 밖으로 빼내 줘.
   - AI 추론 강도(토큰/옵션)를 최적화하고, 빈 응답 시 무조건 재시도하여 대기 시간이 2배가 되는 로직을 개선해 줘.
   - 확장 프로그램의 hover 프로브를 기본 OFF(또는 최소한)로 바꾸고, 팝업이 닫혀도 수집이 끊기지 않도록 처리해 줘.

수정을 시작하기 전에 **2단계 수정 계획**을 먼저 보여줘.

---

2단계 수정 후 속도와 파싱 정확도가 훨씬 좋아졌어. 이제 **[3단계: 다단계 자동 진행 및 시니어 UI 개선]**을 진행하자.

1. **다단계 상태 관리 및 자동 진행**:
   - 기존 한 줄 문자열(`planned_route`) 대신 단계별 상태를 관리할 수 있는 구조로 바꿔줘.
   - 과도한 API 호출을 막기 위해 **① 안내된 대상 요소 클릭, ② URL 변경, ③ 입력 완료(Enter/Blur)** 시점에만 디바운스를 걸어 다음 단계를 자동 재캡처하도록 구현해 줘.
   - AI가 응답으로 `next` / `done` / `blocked`(인증 필요 등) 상태를 명확히 반환하게 하여, 목표 달성 시 세션을 자동 종료해 줘.
2. **시니어 맞춤 오버레이 UI**:
   - 브라우저 오버레이 안내 카드의 글씨 크기를 크게 키우고, 한 번에 한 문장씩 직관적으로 행동 지침만 보여주도록 개선해 줘.
   - 브라우저 내장 TTS(한국어 음성 존재 시 작동, 없으면 조용히 폴백)와 강조 표시를 추가해 줘.

**3단계 수정 계획**을 먼저 보여주고, 확인 후 코드를 수정하자.

---

3단계까지 잘 작동해. 이제 정부24와 대학 포털의 로그인 이후 화면을 테스트하기 위해 **[4단계: 보안 및 개인정보 보호 조치]**를 진행하자.

1. **로컬 서버 인증 및 CORS 제한**:
   - 아무 웹페이지나 로컬 서버(`8765`)를 호출할 수 없도록 확장 프로그램(`background.js`) 경유 호출로 통일하고, 실행 시 생성되는 로컬 인증 토큰과 Origin 검증을 추가해 줘.
2. **개인정보 마스킹 파이프라인**:
   - 서버에서 AI로 데이터를 보내기 전, 주민등록번호, 전화번호, 이메일, 학번/계좌 등 긴 숫자열 패턴을 자동으로 마스킹(`[개인정보]`)하는 필터를 추가해 줘.
3. **결제·최종 제출 단계 안전장치**:
   - 정부24의 "신청·발급·결제"나 포털의 최종 제출 버튼은 숨기지 않되, 시스템 규칙 레벨에서 *"이 단계는 중요하니 내용을 직접 확인하신 후 눌러주세요"*라는 경고 문구가 반드시 포함되도록 강제해 줘.

**4단계 수정 계획**을 먼저 정리해 줘.
