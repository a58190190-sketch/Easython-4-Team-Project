# Easython 소프트웨어 개발 아이디어 2안 기획서

* **문서 버전:** v1.0
* **작성일:** 2026-11-10

---

## 1. 프로젝트 개요

### 1.1 추진 배경 및 목적
* **배경:** 웹사이트 이용에 어려움을 겪는 디지털 취약 계층 다수 존재
* **목적:** 디지털 취약 계층의 웹서비스 이용 능력 증진

### 1.2 기대 효과
* 디지털 취약 계층의 웹서비스 이용시 목적 달성 시간 50%이상 감축

### 1.3 타겟 사용자
* **주요 사용자:** 시니어 50-60세대, 웹사이트 이용에 불편을 겪는 사용자

---

## 2. 개발 범위 및 주요 기능

### 2.1 핵심 기능 목록 (MVP 기준)

| 구분 | 기능명 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :---: |
| 시스템 | 웹사이트 탐색 | 현재 이용자가 사용하고 있는 웹사이트의 정보(클릭 이벤트 등)를 AI에이전트가 스크립트 단위로 분석함. | 상 |
| 시스템 | 웹사이트 사용 방식 인지 | 현재 이용자가 사용하고 있는 화면상 표시된 웹사이트를 분석함. | 상 |
| 시스템 | 웹사이트 보안 확인|웹사이트의 보안(로그인 등)으로 접근불가한 영역이 있는지 확인 후 해결 요구 안내, 단 이용에 직접적으로 연관 되어있지 않은 경우 안내 불필요 | 상 |
| 이용자 | 웹사이트 안내 | 현재 이용자가 이용하길 원하는 서비스를 입력 후 인공지능 에이전트가 해당 서비스 이용 방법을 시각적으로 안내받음(웹사이트 내에서 클릭 해야 하는 UI위에 동그라미등의 도형으로 표시) | 상 |

### 2.2 제외 범위 (Out of Scope)
* 제 3자 개인정보 이용 동의서 작성
* 크롬 외 브라우저 적용

---

## 3. 시스템 아키텍처 및 기술 스택

### 3.1 비기능적 요구사항
* **성능:** 주요 API 응답 속도 5초 이내 유지
* **호환성:** 최신 크롬, 사파리, 엣지 브라우저  지원
* **보안:** 웹사이트의 보안으로 접근불가한 영역이 있는지 확인
* **연속성** 하이퍼링크로 인해 페이지가 바뀌어도 원하는 기능을 완수 할때 까지 수행 지속
