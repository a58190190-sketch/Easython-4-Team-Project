# Easython MVP 실행 안내 (상세 작동 방식 0~3)

## 설치 및 NVIDIA NIM 키 설정

1. 프로젝트 파일을 모두 같은 폴더에 둡니다. Python이 없다면 `install.bat`을 실행해 동봉된 Python 3.14.10 설치를 시작하고, 완료 후 `install.bat`을 다시 실행합니다.
2. `install.bat`이 `requirements.txt`에 적힌 라이브러리를 설치하고 설치 결과를 검증합니다. `run.bat` 또는 `app.py` 실행 시에도 해당 파일을 읽어 모든 패키지의 설치 여부와 버전 조건을 확인합니다. 새 라이브러리를 `requirements.txt`에 추가하면 확인 항목에도 자동 반영됩니다.
3. `run.bat`을 실행합니다. 기본 모델은 `z-ai/glm-5.3-flash`이며 NVIDIA API 키 발급 페이지로 연결됩니다. 최초 실행 시 **NVIDIA NIM API 키 등록** 창이 나타납니다. **NVIDIA API 키 발급 페이지 열기**를 눌러 NVIDIA API Catalog에서 키를 발급받아 입력하세요. 키 연결 확인을 위해 짧은 NIM 요청을 한 번 보내며 크레딧/요금이 적용될 수 있습니다. 키는 Windows 자격 증명 저장소에 보관됩니다.
4. 이후에는 **NVIDIA API 키 설정**에서 저장한 키를 교체할 수 있습니다. 프로그램을 업데이트한 경우 기존 Easython 창을 모두 닫고 `run.bat`으로 다시 실행하세요. 새 메인 창 제목은 `Easython - 메인 기능 입력`입니다.
5. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다. **압축해제된 확장 프로그램을 로드**를 눌러 `chrome_extension` 폴더를 선택합니다.

API 키 발급은 NVIDIA의 [API Catalog Quickstart](https://docs.api.nvidia.com/nim/docs/api-quickstart)를 참고하세요. Python 설치 파일은 Windows x64용 Python 3.14.10이며 SHA-256은 `92480239264744fe0386a1bd8275786fefa126e3129e56a68e22b52c73329965`입니다. Chrome 확장 프로그램 로드는 최초 1회 수동으로 해야 합니다.

## 사용 순서

1. Chrome에서 분석할 일반 웹페이지를 엽니다. Chrome 보안 페이지(`chrome://` 등)는 지원되지 않습니다.
2. 툴바의 Easython 확장 아이콘을 누릅니다.
3. **현재 탭 정보 보내기**를 클릭합니다. URL·제목·HTML이 로컬 Python 서버(`127.0.0.1:8765`)로 전송됩니다. 별도 팝업 없이 Easython 메인 창의 기능 입력란이 활성화됩니다.
4. Easython 메인 창의 기능 입력란에 원하는 기능을 입력합니다. Easython은 현재 페이지의 HTML 크기와 상호작용 요소 수를 계산하고, UI 요소 일부와 목표를 NVIDIA NIM API로 보냅니다. 입력값과 비밀번호 값은 포함하지 않으며 URL 및 링크의 query/hash는 제외합니다.
5. 메인 창에서 페이지 규모, 분석에 포함한 UI 요소 수, 추정 토큰량, 속도 조절 대기와 예상 진행률(%)을 확인할 수 있습니다. 실제 응답이 끝나기 전에는 예상 진행률이 92%를 넘지 않습니다. 보내기 버튼의 `분석중` 점 개수도 바뀌어 요청이 진행 중임을 알 수 있습니다.

6. 화면 분석 결과에서 캡처 해상도와 OpenCV가 찾은 UI 후보 영역 수를 확인합니다. 사이트가 화면보다 가로로 넓거나 페이지가 세로로 길면 앱이 Chrome 최대화/확대율 조절 또는 기능이 있는 영역으로 스크롤하도록 권고합니다. 권고에 따라 화면을 맞춘 뒤 확장 프로그램으로 다시 전송하세요.
7. 기능 입력란은 메인 창 위쪽에 배치되고 앱 시작 시 입력 포커스가 갑니다. 단계 번호나 단계 진행 문구는 화면에 표시하지 않습니다.
8. 원본 페이지가 현재 브라우저 창보다 크더라도 안내 대상 버튼/링크/입력란이 화면에 보이면 스크롤 또는 크기 조정 권고를 표시하지 않습니다. 안내 대상이 없거나 화면 밖일 때만 Chrome 가장자리에 빨간 화살표와 `-방향으로 스크롤` 안내를 표시하고, 스크롤 위치에 따라 방향을 갱신합니다. 안내 요소는 `#FF0000` 색으로 강조됩니다. 메인 창 상단 슬라이더로 가이드 투명도를 0%~100% 조절합니다(기본 10%, 0% 불투명, 100% 투명).
9. 같은 웹사이트에서 첫 분석을 마친 뒤에는 사이트 전체 구조를 다시 보내지 않고, 목표가 달라져도 새로 수신한 현재 화면만 NVIDIA NIM에 분석 요청합니다. 검색/조회/발급 목표 또는 인기 검색어 영역이 감지되면 앱 창의 빨간 안내 문구에 입력할 검색어를 표시하고 사이트 검색창만 표시합니다.
   인기 검색어 영역이 감지되고 목표에 맞는 사이트 검색창이 있으면 인기 항목을 누르는 대신 검색창에 입력할 검색어를 앱에 알려주고 검색창 위치를 표시합니다.
9. 동작 후 화면을 다시 보내면 기존 목표에 맞게 분석합니다. **다시보기**는 저장된 목표 안내를 처음부터 다시 확인하고, **안내 종료**는 안내 표시와 반복 분석을 멈춥니다. 캡처 중 UI가 1.2초 동안 유지되는지도 확인해 안정적인 UI를 우선 안내합니다. 화면 위에는 대상 테두리만 얇게 표시하고 설명과 실제 입력할 검색어는 앱에 표시해 사이트 메뉴를 가리지 않습니다. 화면이 갱신되어 요소가 다시 만들어지면 문구와 속성으로 다시 찾습니다. 자동 클릭/입력은 수행하지 않습니다.

## 요청 속도 제한

앱 내부에서 분당 최대 6회와 추정 입력·출력 20,000 토큰을 보수적 기준으로 두고, 페이지 크기에 따라 추가 대기 시간을 둡니다. NVIDIA 문서는 429를 요청 한도 초과로 정의하지만, 계정별 고정 RPM/TPM 수치를 공개하지 않으므로 이 앱 내부 기준은 실제 계정 한도를 보장하지 않습니다. 같은 키를 쓰는 다른 앱/기기의 요청도 반영할 수 없습니다. 429 응답은 대기 후 최대 3회 재시도합니다.

## 구현 범위

완료: `MVPspec.md` 상세 0~3 (NVIDIA API 키 등록, 확장 연동, URL/HTML/화면 캡처 수집, 채팅 입력, NIM 경로 제안, OpenCV 화면 후보 분석, 브라우저 도형 가이드 및 새 화면 반복 분석).

## 데이터 처리

- 분석 요청은 NVIDIA NIM의 `https://integrate.api.nvidia.com/v1/chat/completions`로 전송됩니다 ([공식 LLM API 안내](https://docs.api.nvidia.com/nim/reference/llm-apis)).
- API 키는 Windows 자격 증명 저장소에 보관합니다. `keyring`은 운영체제 자격 증명 저장소를 사용합니다 ([keyring 문서](https://keyring.readthedocs.io/en/stable/)).
- 원본 HTML은 Python 프로세스 메모리에서 UI 요소 추출에만 사용하며 파일로 저장하지 않습니다.
- 화면 캡처는 Python에서 OpenCV 분석 후 메모리에서 폐기하며, NIM으로 보내지 않습니다.
- NVIDIA NIM에는 페이지 URL(query/fragment 제거), 제목, 페이지 UI 메타데이터와 사용자가 입력한 목표가 전송됩니다. 민감한 페이지에서는 사용하지 마세요.
