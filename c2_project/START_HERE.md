# Easython MVP 실행 안내 (상세 작동 방식 0~3)

## 설치 및 AI 제공자 설정

1. 프로젝트 파일을 모두 같은 폴더에 둡니다. `install.bat` 하나가 Python 설치 여부를 먼저 확인하고, 없으면 동봉된 Python 3.14.10을 설치한 다음 이어서 라이브러리 설치와 검증을 진행합니다.
2. `install.bat`은 프로젝트 전용 `.venv`에 `requirements.txt` 라이브러리를 설치하고 버전 조건을 검증합니다. 새 라이브러리를 `requirements.txt`에 추가하면 다음 설치 때 자동으로 반영됩니다. 직접 앱을 실행할 때는 `.venv\Scripts\python.exe app.py`를 사용하세요.
3. `run.bat`을 실행합니다. 앱은 API 키 없이도 시작합니다. 메인 화면의 **AI 제공자**에서 NVIDIA NIM 또는 Groq를 선택한 뒤 **API 키 설정**을 누릅니다. Groq 기본 모델은 `openai/gpt-oss-20b`입니다. 발급 페이지에서 키를 만든 후 입력하면 짧은 연결 확인 요청을 보내고 Windows 자격 증명 저장소에 보관합니다. 확인 요청에는 제공자 계정 한도나 요금이 적용될 수 있습니다.

기본 GLM-5.3-Flash 요청에는 `reasoning_effort=max`와 최대 출력 토큰 4,096개를 지정합니다. NVIDIA API 요청량 추정에도 이 출력 한도를 포함합니다.
4. 제공자별 키는 별도로 저장되며, 제공자를 바꿔 **API 키 설정**을 열면 해당 제공자의 키를 등록하거나 교체할 수 있습니다. 모델 입력란에는 제공자별 기본 모델이 자동 선택됩니다. 직접 다른 모델명을 입력할 수도 있습니다. 프로그램을 업데이트한 경우 기존 Easython 창을 모두 닫고 `run.bat`으로 다시 실행하세요. 메인 창에서는 모델·키·분석 상태를 관리합니다.
5. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다. **압축해제된 확장 프로그램을 로드**를 눌러 `chrome_extension` 폴더를 선택합니다.

API 키 발급은 NVIDIA의 [API Catalog Quickstart](https://docs.api.nvidia.com/nim/docs/api-quickstart)를 참고하세요. Python 설치 파일은 Windows x64용 Python 3.14.10이며 SHA-256은 `92480239264744fe0386a1bd8275786fefa126e3129e56a68e22b52c73329965`입니다. Chrome 확장 프로그램 로드는 최초 1회 수동으로 해야 합니다.

Easython을 제거하려면 `uninstall.bat`을 실행하세요. 전용 `.venv`와 그 안의 라이브러리를 제거하며, Easython 설치 기록이 있는 Python 3.14.10만 별도로 확인 후 제거합니다. 전역 Python, 전역 패키지, API 키, 재설치용 Python 설치 파일은 보존합니다.

## 사용 순서

1. Chrome에서 분석할 일반 웹페이지를 엽니다. Chrome 보안 페이지(`chrome://` 등)는 지원되지 않습니다.
2. 툴바의 Easython 확장 아이콘을 누릅니다. 처음 사용하면 Easython 로컬 Python 서버 연결 권한을 한 번 요청합니다.
3. 확장 프로그램 팝업의 **원하는 기능을 입력하세요** 칸에 목표를 적고 **입력한 기능으로 현재 화면 분석**을 누릅니다. 입력한 목표는 팝업을 닫아도 저장되어 다음 화면을 보낼 때 이어서 사용할 수 있습니다. Ctrl+Enter로도 전송할 수 있습니다. 확장 프로그램은 명시적으로 요청한 현재 탭만 일시 분석하며, 웹사이트마다 자동 삽입되거나 모든 사이트 권한을 요구하지 않습니다. HTML 전체는 사이트 최초 분석 시, 화면 캡처는 사이트 최초 분석 또는 시각 정보 요청 시에만 로컬 Python 앱으로 전송합니다. 제목과 인기 검색어 문구도 목표 분석에 필요한 경우에만 수집합니다.
4. Python 앱은 HTML에서 상호작용 UI를 추출하고 OpenCV로 전달된 캡처의 크기와 UI 후보 영역을 분석합니다. 원본 HTML과 이미지는 AI 제공자에 보내지 않습니다. AI에는 추출된 UI 메타데이터를 보내며, 제목·인기 검색어 문구는 필요한 요청에서만 포함합니다. 목록 정보를 보고 싶다는 요청에는 그 내용을 가이드에 복사하지 않고 **Show all**, **Contributors**, **더 보기**처럼 전체 정보를 여는 웹사이트 UI를 찾아 클릭하도록 그래픽과 설명 상자를 표시합니다. GitHub Contributors처럼 목록이 이미 화면에 보일 때는 영역을 직접 표시해 확인하도록 안내합니다.
   목표로 하는 클릭/확인 UI가 현재 보이지 않으면 빨간 스크롤·메뉴 열기 가이드를 표시합니다. 확장 프로그램은 이 대기 상태에서만 약 2초마다 현재 탭을 캡처하고, 화면 또는 UI 상태가 바뀐 경우 10초 간격으로 다시 분석해 목표 UI가 나타났는지 확인합니다. 목표 UI를 찾으면 반복 캡처를 멈춥니다. 사용자가 페이지를 벗어나거나 안내를 종료하면 확인도 중단됩니다.
   안내 중 같은 출처의 새 페이지로 이동하면 확장 프로그램이 해당 탭에 가이드를 다시 연결하고 현재 화면을 자동 분석합니다. 다른 출처로 이동하면 Chrome 권한 때문에 자동 연결을 멈춥니다. 새 출처에서 계속하려면 확장 프로그램을 다시 눌러 현재 탭을 전송하세요.
5. 메인 창에서 페이지 규모, 분석에 포함한 UI 요소 수, 추정 토큰량, 속도 조절 대기와 예상 진행률(%)을 확인할 수 있습니다. 실제 응답이 끝나기 전에는 예상 진행률이 92%를 넘지 않습니다. `분석중...`의 점 개수도 바뀌어 요청 진행을 표시합니다. 첫 NVIDIA GLM 분석은 `max` 추론을 유지하며, 같은 사이트의 후속 화면 분석은 더 빠른 `high` 추론과 축소된 화면 메타데이터·대화 이력을 사용합니다. 후속 요청의 앱 자체 최소 대기는 1초이며, 분당 6회·추정 20,000 토큰 제한과 제공자 429 재시도 대기는 유지합니다. 응답 한도 4,096 토큰도 유지합니다.

6. 화면 분석 결과에서 OpenCV 캡처 해상도와 화면 후보 영역 수를 확인합니다. 사이트가 화면보다 가로로 넓거나 페이지가 세로로 길면 앱이 Chrome 최대화/확대율 조절 또는 기능이 있는 영역으로 스크롤하도록 권고합니다. 권고에 따라 화면을 맞춘 뒤 확장 프로그램으로 다시 전송하세요.
7. 기능 입력은 Chrome 확장 프로그램 팝업에서 합니다. 단계 번호나 단계 진행 문구는 화면에 표시하지 않습니다.
8. 첫 분석은 화면에 보이고 안정적인 UI 후보를 우선 표시하며, 클릭/hover 접근 가능성은 아직 판정하지 않습니다. 결과에는 후보 상태가 표시됩니다. **접근성 확인 다시보기**를 누르면 실제 클릭 도달 여부와 hover 접근성을 검사해 다시 안내합니다. 이후의 다시보기는 접근성 확인을 유지합니다. 동작 텍스트 상자는 UI를 덮지 않는 빈 위치에만 표시하며, 빈 위치가 없으면 앱 안내에 표시합니다.
9. 같은 웹사이트에서 첫 분석을 마친 뒤에는 사이트 전체 구조를 다시 보내지 않고, 목표가 달라져도 새로 수신한 현재 화면만 선택한 AI 제공자에 분석 요청합니다. 검색/조회/발급 목표 또는 인기 검색어 영역이 감지되면 앱 창의 빨간 안내 문구에 입력할 검색어를 표시하고 사이트 검색창만 표시합니다.
   인기 검색어 영역이 감지되고 목표에 맞는 사이트 검색창이 있으면 인기 항목을 누르는 대신 검색창에 입력할 검색어를 앱에 알려주고 검색창 위치를 표시합니다.
9. 동작 후 화면을 다시 보내면 기존 목표에 맞게 분석합니다. **안내 종료**는 안내 표시와 반복 분석을 멈춥니다. 캡처 중 UI가 1.2초 동안 유지되는지도 확인해 안정적인 UI를 우선 안내합니다. 텍스트 안내에는 실제 수행 동작과 입력할 검색어를 포함합니다. 화면이 갱신되어 요소가 다시 만들어지면 문구와 속성으로 다시 찾습니다. 자동 클릭/입력은 수행하지 않습니다.
10. 확장 프로그램 아이콘을 눌러 팝업을 열면 **가이드 투명도** 슬라이더가 있습니다. 0%는 불투명, 100%는 완전 투명이며 변경은 페이지 가이드에 실시간 반영됩니다. 기본값은 10%입니다.
11. 목표 기능이 메뉴나 팝업 안에 있으면 Easython은 전체 접근 경로를 안내하고 현재 위치를 갱신합니다. 먼저 화면에 보이는 옵션/메뉴를 열고 확장 프로그램으로 화면을 다시 전송하면, 열린 팝업 안의 다음 UI를 분석해 안내합니다.

## 요청 속도 제한

앱 내부에서 분당 최대 6회와 추정 입력·출력 20,000 토큰을 보수적 기준으로 두고, 페이지 크기에 따라 추가 대기 시간을 둡니다. 이 기준은 실제 제공자 계정 한도를 보장하지 않습니다. 같은 키를 쓰는 다른 앱/기기의 요청도 반영할 수 없습니다. 429 응답은 대기 후 최대 3회 재시도합니다.

API 응답의 `choices`, `message`, `content`가 누락되거나 `content`가 null/빈 값이면 해당 응답 형식과 종료 사유를 분석 오류에 표시하고 한 번 자동 재시도합니다. 재시도 후에도 분석 답변이 없으면 마지막으로 확인된 원인을 안내합니다.

## 데이터 처리

- NVIDIA NIM 요청은 `https://integrate.api.nvidia.com/v1/chat/completions`로, Groq 요청은 `https://api.groq.com/openai/v1/chat/completions`로 전송됩니다. Groq는 OpenAI 호환 Chat Completions API를 제공합니다 ([Groq OpenAI 호환 안내](https://console.groq.com/docs/openai), [API 참조](https://console.groq.com/docs/api-reference)).
- API 키는 Windows 자격 증명 저장소에 보관합니다. `keyring`은 운영체제 자격 증명 저장소를 사용합니다 ([keyring 문서](https://keyring.readthedocs.io/en/stable/)).
- 전체 HTML과 화면 캡처는 수집 정책이 필요하다고 판단한 경우에만 로컬 Python 앱으로 전송합니다. 앱은 HTML에서 조작 UI를 추출하고 캡처를 OpenCV로 분석한 뒤 원본을 파일로 저장하거나 AI 제공자에 전달하지 않습니다.
- 선택한 AI 제공자(NVIDIA NIM 또는 Groq)에는 목표, 추출된 UI 메타데이터와 사이트 주소가 전달됩니다. 제목과 인기 검색어 문구는 해당 목표 분석에 필요한 경우에만 전달됩니다. 입력된 폼 값은 수집하지 않습니다.
